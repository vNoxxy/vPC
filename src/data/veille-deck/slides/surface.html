Un assistant ou un agent IA branché sur le SI a accès à beaucoup de choses : les e-mails, le web, les fichiers, la base clients. Plus ces liens sont larges, plus il devient intéressant pour un attaquant. L’OWASP, la référence en sécurité des applications web, classe l’injection de prompt comme le premier risque des applications à base de LLM.
