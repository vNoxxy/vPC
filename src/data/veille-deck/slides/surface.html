L’IA, nouvelle surface d’attaque

Un assistant ou un agent IA branché sur le système d’information est un logiciel de plus à protéger.

L’injection de prompt

Une consigne cachée dans un e-mail ou une page web détourne l’agent qui la lit. C’est le risque n°1 du Top 10 de l’OWASP pour les applications à base de LLM.

La fuite de données

Ce qu’un salarié colle dans un outil d’IA public peut sortir de l’entreprise.

Des droits trop larges
