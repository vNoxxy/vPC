# Les documents des TP

Dépose ici tes TP en PDF : chacun fait apparaître le bouton « Télécharger le document » sur sa fiche,
dès que le site est reconstruit (à chaque push sur `main`, Vercel ou Netlify s'en occupent).

**Le nom du fichier décide de la fiche** : `glpi.pdf` va sur /realisations/glpi. Un deuxième document
pour la même fiche prend un suffixe : `glpi_annexe.pdf`. Les formats acceptés : PDF (conseillé), DOCX,
ODT, PPTX, XLSX. Tant qu'un fichier manque, la fiche n'affiche simplement pas de bouton.

Pour exporter depuis Google Drive : ouvre le document → Fichier → Télécharger → Document PDF.
Pour un .docx : ouvre-le avec Google Docs (ou Word), puis exporte-le en PDF de la même façon.
